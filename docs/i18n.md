# i18n Guidelines

> Read this before touching `app/src/locales/en.json` or adding/reusing/renaming
> translation keys, or using `useTranslation`/`t()`/`Trans`.

- `app/src/locales/en.json` is the **single source of truth**. Other languages are
  auto-translated from it — only ever edit `en.json`.
- Before adding a key, search `en.json` for an existing key with the same meaning and
  reuse it.

```tsx
const { t } = useTranslation();
t("main.save")           // "Save"
t("main.button_cancel")  // "Cancel"
```

## Namespaces
- Namespace = feature subfolder name under `app/src/features`, in `snake_case`
  (e.g. `Pricing` → `pricing`).
- Use `common` for shared/global UI elements (buttons, labels, common messages).
- Only add namespaces/keys to `en.json` — other locales are handled automatically.

## Adding keys
- Add new keys inside the chosen namespace object, at the end of that object. Create the
  namespace if it doesn't exist.
- `snake_case` key names.
- **No nested sub-objects** — keys sit directly, one level deep, inside the namespace.
  Encode grouping into the key name with `_` instead.

```json
// ❌ Wrong
{ "pricing": { "plans": { "free": { "title": "FREE" } } } }

// ✅ Correct
{ "pricing": { "plans_free_title": "FREE" } }
```
Used as `t("pricing.plans_free_title")`, not `t("pricing.plans.free.title")`.

```json
{ "notifications": { "my_new_key": "My new English text" } }
```

## Interpolation
- Plain values: `"{{variable}}"` in JSON, e.g.
  `"items_selected": "{{count}} items selected"` → `t("notifications.items_selected", { count: 5 })`.
- JSX content (bold text, links): use `<Trans>`.
```tsx
import { Trans } from "react-i18next";

<Trans
  i18nKey="main.agree_to_terms"
  components={{ link: <Link url="/terms" /> }}
/>
```

## Key naming conventions

| Pattern | Use for |
|---|---|
| `button_*` | Button labels (`button_save`, `button_cancel`) |
| `modal_*_title` / `modal_*_description` / `modal_*_button*` | Modal copy |
| `banner_*_title` / `banner_*_description` / `banner_*_button` | Banner copy |
| `toast_*` | Toast messages |
| `tooltip_*` | Tooltip text |
| `inline_*` | Inline validation / helper text |
| `table_column_*` | Table column headers |
| `empty_*` | Empty state headings/descriptions |
| `badge_*` | Badge labels |
